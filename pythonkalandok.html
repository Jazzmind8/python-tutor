Bevezetés

Mi az a Python?

A Python általános célú programozási nyelv. Azért népszerű, mert a kódja olvasható, rövid, és szinte úgy néz ki, mint egy angol nyelvű mondat.

Rövid történet

  • 1989: Guido van Rossum holland programozó karácsonyi szünetben kezdi fejleszteni a nyelvet.
  • 1991: megjelenik az első nyilvános változat. A nevét a Monty Python humoristacsoport után kapta, nem a kígyóról.
  • 2000 és 2008: megjelenik a Python 2, majd a Python 3. A Python 3 tisztább, de nem teljesen kompatibilis az előzővel.
  • 2020: a Python 2 támogatása megszűnt, ma már a Python 3 a használt változat.

Miben más, mint egy objektumorientált nyelv?

A Python többparadigmás nyelv. Támogatja az objektumorientált programozást (osztályok, objektumok), de nem kötelező használni. Lehet egyszerű, eljárásos stílusban is írni, ahogy most mi is tanuljuk. A Java vagy a C# nyelvben viszont minden kódnak osztályban kell lennie. A Pythonban a változók típusát sem kell előre megadni, és a program közvetlenül futtatható, külön fordítási lépés nélkül.

Mire használják az életben?

  • Weboldalak és szerverek készítése (például a Django keretrendszerrel).
  • Adatelemzés és tudományos számítások (például a pandas és a NumPy könyvtárral).
  • Mesterséges intelligencia és gépi tanulás (például a TensorFlow és a PyTorch keretrendszerrel).
  • Ismétlődő feladatok automatizálása: fájlok átnevezése, jelentések készítése.
  • Oktatás: a kezdők első nyelve, mert könnyen olvasható.

Kik használják?

Nagy cégek, például a Google, a YouTube, az Instagram, a Spotify és a NASA is használja különböző feladatokra. Sok egyetem és iskola tanítja Pythont kezdő programozási nyelvként.

I. modul

Alapok

A cél, hogy önállóan tudj egyszerű programokat írni és olvasni.

A Python program utasításokból áll, amelyeket a gép sorban, felülről lefelé hajt végre. A print() parancs kiírja a szöveget a képernyőre. A szöveget idézőjelek közé írjuk.

Példakód megnyitása 
print("Hello, világ!")
print("Ez az első programom.")
print(2 + 3)
A harmadik sorban nincs idézőjel, mert a Python a számot kiszámolja, és az 5-öt írja ki.
Feladat: írd ki a nevedet és a kedvenc állatodat két külön sorban.

A változó olyan doboz, amelynek nevet adunk, és értéket teszünk bele. Az értéknek típusa van: int (egész szám), float (tizedes szám), str (szöveg) és bool (igaz vagy hamis). A type() megmondja, melyik típus.

Példakód megnyitása 
nev = "Anna"
kor = 12
magassag = 1.52
kedvenc = True

print(nev, kor, magassag)
print(type(nev))       # str
print(type(kor))       # int
print(type(magassag))  # float
print(type(kedvenc))   # bool
Feladat: hozz létre egy változót a saját magasságoddal, és írasd ki a típusát.

Az egyenlőségjel (=) értékadás: a jobb oldali értéket a bal oldali változóba teszi. Nem azt jelenti, hogy „egyenlő”. A számokkal szokásos műveleteket végezhetünk: + - * /, egész osztás //, maradék % és hatványozás **.

Példakód megnyitása 
a = 7
b = 2
print(a + b)    # 9
print(a - b)    # 5
print(a * b)    # 14
print(a / b)    # 3.5
print(a // b)   # 3  (egész osztás)
print(a % b)    # 1  (maradék)
print(a ** b)   # 49

a = a + 10      # a most 17
print(a)
Feladat: számold ki, hány perc van 3 órában, és hány maradék perc marad, ha 100 percet osztunk 60-nal.

Az input() kérdez a felhasználótól, és szövegként ad vissza egy értéket. Számmal az int() vagy float() függvénnyel dolgozhatunk. Az f-stringben a {} jelek közé írt változó értéke kerül a szövegbe.

Példakód megnyitása 
nev = input("Mi a neved? ")
kor = int(input("Hány éves vagy? "))
print(f"Szia, {nev}! Jövőre {kor + 1} éves leszel.")
Feladat: kérdezd meg a barátod nevét és kedvenc számát, és írj ki egy mondatot a kettővel.

Az if döntést hoz: ha a feltétel igaz, a behúzott sorok futnak le. Az elif és az else további lehetőségeket ad. A behúzás (4 szóköz) a Pythonban kötelező.

Példakód megnyitása 
pontszam = int(input("Pontszám (0-100): "))

if pontszam >= 90:
    print("Jeles!")
elif pontszam >= 75:
    print("Jó!")
elif pontszam >= 50:
    print("Megfelelt.")
else:
    print("Gyakorolj még!")
Feladat: írj programot, amely megmondja, páros vagy páratlan-e egy beírt szám. (Tipp: szam % 2)

Az összehasonlítások igaz vagy hamis értéket adnak: == (egyenlő), != (nem egyenlő), >, <, >=, <=. A and akkor igaz, ha mindkét oldal igaz. Az or akkor igaz, ha legalább az egyik. A not megfordítja az értéket.

Példakód megnyitása 
eso = True
napsut = False

print(eso and napsut)   # False
print(eso or napsut)    # True
print(not eso)          # False

x = 5
print(x == 5)           # True
print(x != 3)           # True
Feladat: írj programot, amely akkor írja ki, hogy „Mehetsz strandra”, ha süt a nap és nincs eső.

A for ciklus előre meghatározott számú alkalommal ismétel. A range() számsort ad meg: range(5) a 0, 1, 2, 3, 4 számokat adja (5-öt nem), range(1, 6) az 1-től 5-ig, a harmadik paraméter a lépésköz.

Példakód megnyitása 
for i in range(3):
    print("Szia!", i)

for i in range(10, 0, -2):
    print(i)    # 10, 8, 6, 4, 2
Feladat: írasd ki a 1-től 10-ig a számok négyzetét.

A while ciklus előbb ellenőriz: ha a feltétel igaz, lefut a ciklus törzse, ha hamis, egyszer sem. Fontos, hogy a törzsben változzon valami, különben a ciklus soha nem ér véget.

Példakód megnyitása 
szamlalo = 3
while szamlalo > 0:
    print("Visszaszámlálás:", szamlalo)
    szamlalo = szamlalo - 1
print("Indul!")
Feladat: írj visszaszámlálást 10-től, és a végén írd ki: „Robbanás!”.

Összerakjuk az eddigi tudást egy játékba. A gép választ egy titkos számot, a játékos tippel, a program pedig megmondja, hogy nagyobb vagy kisebb a tipp.

Példakód megnyitása 
import random

titok = random.randint(1, 20)
tipp = 0

while tipp != titok:
    tipp = int(input("Tippelj egy számot 1 és 20 között: "))
    if tipp < titok:
        print("Nagyobb!")
    elif tipp > titok:
        print("Kisebb!")

print("Eltaláltad!")
A random részletét a III. modulban tanuljuk. Most elég annyit tudni, hogy véletlen számot ad.
Feladat: számold meg, hány tippből találta el a játékos a számot, és írd ki a végén.

Kiegészítő fogalmak komment, break, continue

Komment: a # jel után írt szöveget a Python figyelmen kívül hagyja. A megjegyzés csak az olvasónak szól, a gép nem futtatja.

Példakód: komment 
# Ez egy megjegyzés, a gép nem olvassa el.
print("Ez lefut.")  # ez a sor is lefut

break: azonnal kilép a ciklusból, akkor is, ha a feltétel még igaz lenne. A ciklus utáni sor fut le.

Példakód: break 
for i in range(1, 11):
    if i == 5:
        break
    print(i)
print("Vége a ciklusnak!")
Itt csak 1-től 4-ig íródnak ki a számok, aztán a break kiugrik a ciklusból.

continue: kihagyja az aktuális lépést, és a ciklus a következővel folytatódik.

Példakód: continue 
for i in range(1, 8):
    if i % 2 == 0:
        continue
    print(i)
A páros számoknál a continue átugrik a print sorra, így csak a páratlanok íródnak ki.
Feladat: írj programot, amely számokat kér, és a „0” beírásakor kilép. Csak a pozitív számokat írja ki (continue segítségével).

II. modul

Adatok

Listák, tömbök (rácsok) és szöveges adatok. A gyerekek megtanulják, hogyan kezelnek sok adatot egyszerre.

A lista több értéket tárol egy névvel. Az elemek sorszámozva vannak, 0-tól kezdve. A lista[-1] az utolsó elemet adja. A len() megmondja, hány elem van benne.

Példakód megnyitása 
gyumolcsok = ["alma", "körte", "szilva"]
print(gyumolcsok[0])     # alma
print(gyumolcsok[-1])    # szilva
print(gyumolcsok[0:2])   # ['alma', 'körte']
print(len(gyumolcsok))   # 3
Feladat: készíts listát a kedvenc ételeidről, és írd ki a másodikat.

Új elemet a append() a végére, az insert() adott helyre tesz. A remove() törli az első egyező elemet. Egy elem átírható a sorszámával.

Példakód megnyitása 
lista = [3, 8, 1]
lista.append(5)       # [3, 8, 1, 5]
lista.insert(0, 10)   # [10, 3, 8, 1, 5]
lista.remove(8)       # [10, 3, 1, 5]
lista[1] = 99         # [10, 99, 1, 5]
print(lista)
Feladat: egy üres listába gyűjtsd be a felhasználó által beírt szavakat, amíg a „vége” szót nem írja be.

A for ciklus egyesével végigmegy a listán. Így összeadhatunk, megszámolhatunk vagy kikereshetünk elemeket.

Példakód megnyitása 
pontok = [12, 7, 20, 15]

osszeg = 0
for p in pontok:
    osszeg = osszeg + p
print("Összeg:", osszeg)

legnagyobb = pontok[0]
for p in pontok:
    if p > legnagyobb:
        legnagyobb = p
print("Legnagyobb:", legnagyobb)
Feladat: számold ki a listában a páros számok darabszámát.

A tömb olyan adatszerkezet, ahol az elemek táblázatba, sorokba és oszlopokba rendeződnek. Pythonban ezt úgy készítjük, hogy egy listában listák vannak. Az elemre két sorszámmal hivatkozunk: először a sor, utána az oszlop sorszáma.

Példakód megnyitása 
tabla = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]

print(tabla[1][2])    # 6

for sor in tabla:
    for elem in sor:
        print(elem, end=" ")
    print()
Feladat: készíts 3×3-as táblázatot, amelyben az átlóba 1-est írsz, a többi helyre 0-t.

A hátultesztelős ciklus előbb lefut, és csak utána ellenőriz. A Pythonban nincs külön kulcsszava, ezért while True ciklust használunk, és a break utasítással lépünk ki belőle, amikor a feltétel teljesül.

Példakód megnyitása 
while True:
    jelszo = input("Add meg a jelszót: ")
    if jelszo == "titkos":
        break
    print("Hibás, próbáld újra!")

print("Sikerült, beléptél!")
A ciklus legalább egyszer lefut, mert a feltétel a törzs után van.
Feladat: írj programot, amely addig kéri a számot, amíg a játékos 10 és 20 közötti számot nem ad meg.

A szöveg (str) is olyan, mint egy lista: betűi sorszámozottak. Olyan műveletek vannak rá, mint a upper() (nagybetűs), a lower() (kisbetűs) és a len().

Példakód megnyitása 
szo = "Programozás"
print(len(szo))          # 11
print(szo.upper())       # PROGRAMOZÁS
print(szo[0:3])          # Pro
print("gram" in szo.lower())  # True
Feladat: kérj be egy szót, és írd ki fordítva (tipp: szo[::-1]).

Ha egy ciklus belsejében másik ciklus fut, a belső minden külső lépésnél végigfut. Így szorzótáblát vagy rácsot lehet rajzolni.

Példakód megnyitása 
for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end="\t")
    print()
Feladat: rajzolj ki egy csillagokból álló háromszöget: az első sorban 1 csillag, a másodikban 2, és így tovább 5-ig.

A lista elemeinek száma és összege alapján kiszámolható az átlag. Ez egy valódi feladat: például egy osztály jegyeinek átlagát.

Példakód megnyitása 
szamok = [4, 8, 15, 16, 23]
atlag = sum(szamok) / len(szamok)
print("Átlag:", atlag)     # 13.2
Feladat: írj programot, amely bekér 5 jegyet, majd kiírja az átlagot és a legjobb jegyet.

A kérdéseket és válaszokat egy listában tároljuk. A program végigkérdezi őket, és a végén megmondja a pontszámot.

Példakód megnyitása 
kerdesek = [
    ("Mennyi 2 + 2?", "4"),
    ("Mi Magyarország fővárosa?", "Budapest"),
    ("Hány lába van egy pók?", "8"),
]

pontok = 0
for kerdes, valasz in kerdesek:
    tipp = input(kerdes + " ")
    if tipp.lower() == valasz.lower():
        pontok = pontok + 1
        print("Helyes!")
    else:
        print("Sajnos nem. A válasz:", valasz)

print("Pontod:", pontok, "/", len(kerdesek))
Feladat: bővítsd a kvízt legalább öt kérdéssel a saját témáidból.

Kiegészítő fogalmak szótár, tuple, beépített függvények

Szótár (dict): kulcs és érték párokat tárol. A kulcs alapján keresünk, nem sorszám alapján. Kapcsos zárójelet használunk.

Példakód: szótár 
pontok = {"Anna": 12, "Bence": 9}
print(pontok["Anna"])          # 12
pontok["Csilla"] = 15          # új pár hozzáadása
for nev, pont in pontok.items():
    print(nev, pont)

Tuple (rendezett elemsor): olyan, mint a lista, de nem módosítható. Kerek zárójelet használunk.

Példakód: tuple 
koordinata = (3, 5)
print(koordinata[0])     # 3
# koordinata[0] = 7      # ez hibát adna, mert a tuple nem módosítható

Beépített függvények listához: a sum() összeget, a min() a legkisebbet, a max() a legnagyobbat, a sorted() rendezett listát ad vissza.

Példakód: beépített függvények 
szamok = [4, 9, 1]
print(sum(szamok), min(szamok), max(szamok))   # 14 1 9
print(sorted(szamok))                          # [1, 4, 9]
Feladat: készíts szótárat öt tanuló nevéhez és pontszámához. Írd ki a legjobb tanulót.

III. modul

Függvények és kisprojektek

Az eljárások és függvények segítségével a programot kisebb, újrahasználható darabokra bontjuk. A modul végén a gyerekek önálló kis játékot írnak.

Az eljárás (függvény) egy névvel ellátott utasítássor. A def kulcsszóval definiáljuk, és a nevével hívjuk meg. Egyszer megírjuk, többször használjuk.

Példakód megnyitása 
def koszon():
    print("Helló!")
    print("Jó munkát kívánok!")

koszon()
koszon()
Feladat: írj eljárást, amely egy keretet rajzol ki csillagokból, és hívd meg kétszer.

A paraméter az a bemenet, amit a függvénynek átadunk. A return utasítás visszaad egy értéket a hívónak. Ha nincs return, a függvény „nem ad vissza semmit”.

Példakód megnyitása 
def negyzet(szam):
    return szam * szam

print(negyzet(4))     # 16

def osszeg_es_atlag(a, b):
    ossz = a + b
    return ossz, ossz / 2

ossz, atl = osszeg_es_atlag(3, 7)
print(ossz, atl)      # 10 5.0
Feladat: írj függvényt, amely egy hőmérsékletet Celsius-ról Fahrenheitre vált át (F = C × 9 / 5 + 32).

A függvényen belül létrehozott változó lokális: csak a függvényben látszik. A függvényen kívül létrehozott változó globális. A függvényen belül ne írjunk globális változót, inkább adjunk át paramétert.

Példakód megnyitása 
hely = "globális"

def fuggveny():
    hely = "lokális"
    print(hely)

fuggveny()        # lokális
print(hely)       # globális
Feladat: mit fog kiírni a program, ha a függvényben módosítod a változó értékét? Döntsd el előre, aztán próbáld ki.

A Python tele van kész eszközökkel. Ezeket az import utasítással hívjuk be. A random modul véletlent ad, a math modul matematikai függvényeket.

Példakód megnyitása

import math

print(random.choice(["kő", "papír", "olló"]))
Feladat: írj programot, amely két dobókockát dob, és kiírja az összeget.

A gép véletlenszerűen választ. A játékos megadja a választását, a program pedig eldönti, ki nyert.

Példakód megnyitása

    print("Te nyertél!")
else:
    print("A gép nyert.")
Feladat: egészítsd ki a játékot úgy, hogy háromszor játszanak, és a végén kiírja az állást.

Ha a program hibába futna (például szöveget próbálunk számmá alakítani), a try és except szerkezettel elkapjuk a hibát, és szépen reagálunk rá.

Példakód megnyitása

    print("Ez nem szám volt!")

Nagyobb programot érdemes függvényekre bontani. A main() függvény irányítja a programot. A if __name__ == "__main__": sor azt biztosítja, hogy a program csak akkor induljon, ha közvetlenül futtatjuk.

Példakód megnyitása 
def udvozlet():
    print("Üdv a játékban!")

def main():
    udvozlet()
    print("Játék vége.")

if __name__ == "__main__":
    main()
Feladat: bontsd a kő-papír-olló játékodat legalább három függvényre.

Háromféle hiba van: a szintaktikai hiba (elgépelés, hiányzó kettőspont), a futásidejű hiba (futás közben áll meg a program) és a logikai hiba (lefut, de rossz eredményt ad). A logikai hibát a print()-tel tudjuk a legkönnyebben megkeresni.

Példakód megnyitása 
def atlag(szamok):
    osszeg = 0
    for sz in szamok:
        osszeg = osszeg + sz
        print("Eddig:", osszeg)     # ellenőrző kiírás
    return osszeg / len(szamok)

print(atlag([2, 4, 6]))
Feladat: keress hibát a fenti kódban, ha a visszatérési értéket rossz helyre írjuk. Mi a helyes sorrend?

Kiegészítő fogalmak None és a függvény-dokumentáció

None: a Python „semmi” értéke. Ha egy függvénynek nincs return utasítása, a visszatérési értéke None lesz.

Példakód: None 
def koszon():
    print("Szia!")

eredmeny = koszon()
print(eredmeny)     # None

Dokumentáció (docstring): a függvény első sorába írt három idézőjeles szöveg leírja, mit csinál a függvény. Ezt a kódolók mások számára írják.

Példakód: docstring 
def negyzet(szam):
    """Visszaadja a szám négyzetét."""
    return szam * szam

print(negyzet.__doc__)
Feladat: írj egy függvényt, amelynek van docstringje, és a docstringben írd le, mit csinál, és milyen bemenetet vár.
